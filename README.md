# Book Club

Biblioteca privada con perfiles, tomos, lector 3D, notas y narración.

## Enlaces

- Código: [github.com/villeladante374-pixel/dove-nova-tundra-stone](https://github.com/villeladante374-pixel/dove-nova-tundra-stone)
- Instalador Windows: [BookClub-Windows.zip](https://github.com/villeladante374-pixel/dove-nova-tundra-stone/releases/latest/download/BookClub-Windows.zip)

## App de escritorio

1. Descarga `BookClub-Windows.zip`
2. Extrae la carpeta
3. Abre `Instalar.bat` (o `Book Club.exe`)
